Important if you're printing this: the QR code points at this computer's current network address. If the Wi-Fi/network changes later (different router, IP reassigned after a reboot, moved to a different room), a printed copy will stop working and you'll need to come back here and print a new one. For something posted long-term, ask IT/network admin to reserve a fixed IP for this PC (a "DHCP reservation") so the address never changes.
